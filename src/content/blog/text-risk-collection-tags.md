## 为什么盯上了催收记录

贷后系统里每天新增几万条催收通话记录，是催收员在通话结束后手敲的自由文本。格式五花八门，内容却很有价值：客户是否承认欠款、是否承诺还款、是否失联、是否有共债压力，这些信号在结构化字段里几乎看不到，但每条记录里都写着。

我们最初的目标很朴素：从文本里抽四个标签，接进贷后策略的分层里。真正动手之后才发现，七成工作量在清洗，两成在标注，建模只占一成。

## 脏文本比想象中脏

这些文本的噪声来源非常多：语音转写的错字、拼音混输、表情符号、随手打的缩写、复制粘贴的模板话术。下面是我们在真实数据上统计出的几个典型问题，按出现频率排序。

| 问题类型 | 示例 | 处理方式 |
| --- | --- | --- |
| 同音错字 | 「还宽」表示还款 | 维护业务词典做归一 |
| 拼音缩写 | 「hq」表示还钱 | 用高频缩写表替换 |
| 模板话术 | 「已告知相关法律法规」 | 识别后整段剔除 |
| 无意义填充 | 「嗯嗯好的知道了」 | 长度与信息熵双阈值过滤 |
| 敏感与个人信息 | 手机号、身份证片段 | 正则脱敏后再入库 |

脱敏这一条是硬要求，任何进入训练集的文本都必须先过一遍脱敏，否则标注同事在标注界面看到的全是真实手机号。

## 弱标注：先用规则把量做起来

人工标注四万条的成本我们扛不住，所以先用规则做弱标注，把数据规模拉到可用，再用人工抽检校准。规则的设计原则是可解释、可回溯，每条规则都要能说出它为什么成立。

```python
import re

RULES = {
    'promise_pay': [r'承诺.{0,4}(还款|处理)', r'今天.{0,4}还', r'明天.{0,4}转'],
    'contact_lost': [r'关机', r'空号', r'停机', r'无法(接通|联系)'],
    'dispute': [r'不是我.{0,2}(借|用)', r'不认(可|账)', r'报警'],
    'hardship': [r'失业', r'生病', r'住院', r'家里.{0,4}(困难|出事)'],
}

def weak_label(text: str) -> list[str]:
    hits = []
    for label, patterns in RULES.items():
        if any(re.search(p, text) for p in patterns):
            hits.append(label)
    return hits
```

规则跑完后，四个标签的覆盖率差异很大：`contact_lost` 覆盖了 11%，而 `dispute` 只有 1.2%。对于样本过少的标签，我们不去硬凑正样本，而是在策略里单独走人工复核通道。

## 从规则到模型：什么时候值得上分类器

规则的问题是会互相打架，一条文本里同时出现「承诺还款」和「失业」，规则只能都打上，无法给出置信度。这时候分类器就有价值了，它能把冲突信号压成一个概率。

我用的基线很轻：`TF-IDF` 加线性模型，字符级 n-gram 与词级特征拼接。这个方案在四万条数据上训练不到一分钟，`F1` 能到 0.82 左右，足以支撑策略分层。上大模型之前，我先问自己一个问题：这 0.82 和 0.88 之间的差距，对策略分层到底有没有影响？多数时候没有。

> 在文本风控里，标注质量的上限比模型结构的上限更重要。把标注规范写清楚带来的收益，通常超过换一个更大的模型。

## 人工抽检与标注一致性

弱标注的模型会有系统性偏差，必须靠人工抽检纠正。我设计的抽检流程是分层的：每个标签随机抽 200 条，另加所有模型置信度在 0.4 到 0.6 之间的边界样本 200 条。前者估计整体质量，后者专门找模型的模糊地带。

一致性用两个标注员的重叠样本计算 `Cohen's kappa`。我们第一轮只有 0.61，问题出在「困难」这个标签的边界上：客户说「最近手头紧」算不算困难？后来把定义收紧成「明确提及失业、重大疾病、家庭变故三类事件」，kappa 提到 0.84，模型 F1 也跟着涨了 0.05。

这件事让我确认了一个结论：标注规范文档写得越细，模型效果越好，而写文档这件事没有技术含量，只有愿不愿意做。

## 抽取与落地

最后交付的不是一个模型，而是三样东西：四条标签的模型、一套可解释的关键词命中规则，以及一份标注规范。策略侧用模型分数做主分层，用关键词命中做解释，这样当客户投诉「为什么把我标记为失联」时，我们能拿出具体的文本依据。

整个项目从启动到上线用了七周，其中两周半在清洗和脱敏，两周在标注规范，不到一周在建模。如果你也在做类似的事，我的建议是先把清洗和标注的钱花了，模型那部分可以最后再想。
